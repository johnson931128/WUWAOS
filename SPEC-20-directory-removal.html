Spec 20：刪除資料夾及確認 ​

目標與範圍 ​

使用 rm <path> 刪除檔案或資料夾；資料夾的內容與子目錄一併刪除。對資料夾顯示目標路徑及警告，要求輸入 Y/N 並按 Enter；Y/y 才刪除，N/n、空白、其他輸入或讀取錯誤皆取消。既有一般檔案刪除不新增確認；路徑可相對或絕對，目錄尾端 / 可使用。不加入測試程式碼。

設計及演算法 ​

shell 先呼叫既有檔案刪除；核心回報目標是目錄時，shell 顯示警告，只有確認才呼叫新的 SYS_FS_REMOVE_TREE。確認是 shell 的互動行為；系統呼叫本身不負責顯示提示。

核心再次解析目錄，先以廣度優先走訪所有 inode（索引節點），跳過 .、..，檢查重複節點與索引界限，並確認樹內沒有任何非 Zombie 活躍行程的目前工作目錄；根目錄和特殊目錄名稱不可刪除。檢查通過後反向處理走訪結果，先移除子項，最後移除父項；各項先從父目錄移除，再回收 inode 和資料區塊。記憶體受 WUFS 128 個 inode 上限約束，避免遞迴耗盡核心堆疊。執行於目前單核心、核心內不搶占的模型。檢查並非完整磁碟損毀修復機制。

磁碟錯誤時立即停止並回傳錯誤；WUFS 尚無 journal（日誌）或交易回復，途中失敗可能留下部分已刪除項目或未回收資源，不可保證全有或全無。-16 表示目錄樹包含活躍行程的工作目錄，需先讓行程離開或結束。根目錄與 .、.. 不可刪除。shell 因使用者映像大小限制以 -Oz 編譯，其他程式維持既有最佳化。

執行與驗收 ​

更新核心、shell、使用者 API、規格和網站；以獨立 QEMU 磁碟驗證 N、非法輸入、Y/y、巢狀刪除、一般檔案、根目錄保護、活躍行程工作目錄保護與目錄尾端 /。建置與操作不新增測試程式碼。

QEMU 驗收：N 與 xyz 均取消且資料仍在；Y 刪除多層檔案，y 可刪尾端 / 的目錄。當 shell 或 worker 使用目錄時回傳 -16，worker 結束或 shell 離開後可刪除；rm / 拒絕，rm file/ 不會刪除一般檔案。錯誤注入、磁碟故障和所有磁碟損毀情境尚未驗證。

觀念參考 notes/Chapter 13 file system Interface.md 的目錄結構、notes/chapter 14 File-System Implementation.md 的配置及回收；上述流程為 WUWAOS 現有 WUFS 的簡化實作。
