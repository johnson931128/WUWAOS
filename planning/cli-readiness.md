# WUWAOS CLI 日常使用準備

目標是在 Windows 用 `WUWAOS` 開機，可靠地編輯、保存及重開文字和 C 原始碼。每階段各自提交，最後一起推送。

1. **系統磁碟復原**。`WUWAOS` 能處理待重播的 journal，讓已提交的變更可以讀回。正常磁碟仍由 Flash 載入，無效紀錄交由核心拒絕，不清除待復原資料。
2. **文字編輯容量**。`fan` 可以開啟、修改及保存超過 2 KiB 的原始碼，並在檔案超出新上限或保存失敗時保護原檔。
3. **資源與同步驗收**。以重複啟動外部程式、管線及錯誤後重試確認 shell 可繼續操作。核對行程、FD、頁框，以及滿盤時的保存行為。只針對可重現的阻塞問題修改核心。

## 驗收紀錄

- 階段 1：原生 Windows QEMU 從含空格的目錄執行 `WUWAOS`，通過乾淨 Flash 開機、有效 journal 重播、下次以 Flash 重啟並讀回資料、無效 journal 拒絕復原且磁碟 SHA-256 一致。重播案例用已提交的 journal 測試映像，未模擬實際斷電。
- 階段 2：`fan` 在使用者 heap 保留 32 KiB 編輯空間。QEMU Flash CLI 已驗證開啟 32,767 bytes、再插入一個 byte 並保存到 32 KiB、拒絕插入超限 byte，以及超限檔案保持原樣。測試關機後會讀取磁碟核對兩份內容。
