# 07 · 資料怎麼進出：I/O 與磁碟

`read(fd, buffer, n)` 的 `fd` 是行程內的一個編號，叫[檔案描述符](./glossary.md#fd)。核心用它找出資料來自哪裡。對程式來說，資料可能來自磁碟上的檔案、另一個程式的 Pipe，或終端機輸入。

## 同一個 read，三種等待條件

作業系統用統一介面讓程式從不同來源收 bytes。終端機要等輸入，Pipe 要等寫端填入資料，磁碟要等請求和傳輸完成。這三條路徑共用 `read()` 的入口，核心從 FD 找出對應物件，再用各自的等待條件處理。

教科書常用輪詢、中斷、DMA 分別說明三件事。輪詢是主機反覆察看裝置何時完成，中斷是裝置在完成時通知 CPU，DMA 說明裝置可直接存取交付給它的記憶體緩衝區。在 WUWAOS 的 QEMU 模型中，VirtIO 使用放在客體記憶體中的描述符、佇列與緩衝區。CPU 可以先交出請求，讓執行緒等待事件，完成後才收取結果。

## FD、Pipe 和終端

- **FD 與 OFD**：每個行程有自己的 FD 表。一般開啟物件另有一筆 [OFD](./glossary.md#ofd)，保存物件種類和讀寫位置。`dup()`、`dup2()` 和 `fork()` 可以讓不同 FD 指到同一筆 OFD，因此共享讀寫位置。關閉 FD 會減少 OFD 引用。
- **Pipe**：核心用一段有上限的緩衝區傳遞 bytes。空 Pipe 還有寫端時，讀者等待；資料讀完且最後一個寫端消失時，讀取回傳 0。寫入端遇到沒有讀者時會收到 `ERR_BROKEN_PIPE`。Shell 用 `dup2()` 把各個程式的標準輸入或輸出接到對應端點。
- **終端**：UART 和圖形 [TTY](./glossary.md#tty) 可供 Shell 收字符、寫輸出。存取終端的 FD 仍透過相同 I/O 入口，核心依端點種類把資料送到對應裝置或畫面。

用 [FD／OFD 互動教學](../topics/file-descriptors.md)操作 `open()`、`dup()` 和 `fork()`，觀察哪些描述符共用讀寫位置。

## 一次磁碟讀取的路徑

1. `io_read()` 取得來源物件，WUFS 找出需要讀的[磁區](./glossary.md#sector)。WUFS 的磁碟格式見[第 09 章](./09-filesystem.md)。
2. [VirtIO](./glossary.md#virtio) Block 驅動準備磁碟請求，寫入裝置佇列後通知 QEMU。請求包含磁區、操作與傳輸緩衝區。
3. 開機可用[輪詢](./glossary.md#polling)等完成。一般執行期間，呼叫者透過核心事件等待，讓出 CPU。裝置完成由 [PLIC](./glossary.md#plic) 派發中斷，或由輪詢路徑走共用的完成檢查。
4. 呼叫者恢復、收取結果，再把已取得的資料寫到使用者緩衝區。驗證使用者位址與寫入觸發 COW 的行為見[第 08 章](./08-virtual-memory.md)。

每顆 Block 裝置的請求和傳輸緩衝區持有至完成收取。逾時時先確認裝置已安全重設，才能隔離裝置並回傳錯誤。無法確認裝置停止存取緩衝區時，核心停止執行以保護記憶體。這是磁碟失敗路徑，應用程式也要依 `read()`／`write()` 回傳的實際長度處理部分傳輸。

既有 CLI 驗收涵蓋管線、檔案讀寫和 IRQ，Block reset 故障情境的驗證邊界見整合紀錄。 [I/O 實作](https://github.com/johnson931128/WUWAOS/blob/3a3b273/kernel/io/io.c) · [Block 驅動](https://github.com/johnson931128/WUWAOS/blob/3a3b273/drivers/virtio/block.c) · [FD 與管線規格](../SPEC-27-file-descriptors-and-shell-pipelines.md) · [Block 整合紀錄](../merge-2026-11-10.md)

### 讀取結果要看回傳長度

請求讀 32 bytes 時，Pipe 目前可能只有 8 bytes。讀者先處理已回傳的部分，下一次讀取再依剩餘資料與寫端狀態前進。若 Pipe 已空且最後一個寫端關閉，讀 0 bytes 代表到達末尾。磁碟路徑則要看檔案位移、讀取長度和裝置結果。 [Pipe 讀寫](https://github.com/johnson931128/WUWAOS/blob/main/kernel/io/io.c#L368) · [裝置完成處理](https://github.com/johnson931128/WUWAOS/blob/main/drivers/virtio/block.c#L372)
