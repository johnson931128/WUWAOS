本機與遠端整合（2026-11-10） ​

本機基底為 544e202，未提交工作先保存為 0803032；遠端合併來源為 4177adb。合併保留雙方提交歷史。

範圍本機工作遠端更新合併結果
開機與模組舊版平面目錄、QEMU -kernel模組分層、flash 載入 WUFS 的 /boot/kernel.elf保留遠端目錄與兩種開機入口
Block明確裝置所有權、完成檢查、計數per-device gate/event/bounce、非同步等待、有界 reset/offline採遠端生命週期，加上本機診斷計數；IRQ/poll 共用完成檢查
外部中斷有界 FDT 解析、PLIC 路由與派發以 scheduler polling 收集裝置事件移植為 arch/riscv/fdt.* 與 irq.*，保留 polling 備援
FS／VM 同步排序 KernelMutex、FIFO ownership handoffKernelGate、取消延遲、VM pin/revoke、WUFS journalruntime 使用遠端 gate；mutex 與主機測試保留為獨立原型
使用介面與文件PLIC／請求原型規格多視窗 Terminal、互動教學與網站保留遠端功能，補上整合註記與目前驗證範圍

PLIC callback 先 ACK VirtIO，再呼叫共用 poll_device，最後由 dispatcher complete PLIC claim。Callback 不睡眠、不輸出、不切換行程、不歸還 DMA buffer；event 通知可把等待者排入 Ready queue。process_wait_allowed 拒絕 IRQ context。Kernel 全域中斷及單 hart 政策不變。未支援裝置樹或 PLIC 路由時沿用 polling。

ps 顯示 PLIC handled/spurious、unhandled/invalid/budget，以及每顆磁碟的 state、submitted/completed、io_errors/protocol_errors、offline。正常閒置時 submitted/completed 相等；發生 reset/offline 後，失敗提交可能沒有正常 used-ring completion，不保證兩者相等。

本機兩份 Spec 32／33 保留合併前設計背景與原編號；與遠端同號文件以檔名區分。其同步等待、直接 fail-stop 和「尚未編譯」描述屬歷史階段，現況以本文為準。kernel/proc/kmutex.* 沒有接入 runtime，不可把它的主機測試當成 FS／VM gate 或 RV64 context-switch 驗證。

編譯時另移除遠端 FS 內只有賦值、沒有讀取的 format_version，以通過 portable Clang 23 的 -Wall -Wextra -Werror。

開機入口 ​

Windows PowerShell 在 D:\WUWAOS，使用現有 portable 環境：

powershell
.\Start-WUWAOS.cmd gui     # 原生 QEMU 圖形視窗
.\Start-WUWAOS.cmd         # UART；QEMU 直接載入核心
1
2

真正從 WUFS 磁碟載入核心，可先執行 .\Start-WUWAOS.cmd shell，再於 Bash 輸入：

bash
make run-disk
1

該模式使用唯讀 build/boot-flash.img 與 build/wuwaos-cli.img，由 OpenSBI → flash loader → /boot/kernel.elf 啟動 CLI，不使用 QEMU -kernel。文字模式按 Ctrl+A，放開後按 X 結束。圖形模式關閉 QEMU 視窗。使用同一映像時先結束前一個 session。

  • Portable 工具檢查通過；QEMU 11.1.3、Clang／LLD／LLVM 23.1.4。
  • RV64 kernel、strip 後的磁碟核心與 flash loader 編譯通過。
  • .\Test-KernelMutex.cmd 四組主機測試通過。
  • QEMU 11.1.3／OpenSBI 1.8.1 以 serial TCP 執行 smoke checks，使用獨立測試映像；未修改日常使用的磁碟。
  • build/merge-smoke-20261110-093314/：直接 -kernel 開機、WUFS／swap 順序互換、flash → WUFS 磁碟開機均通過。驗證 ps → ls /boot → ps 的 WUFS handled 增加、IRQ 錯誤為零，以及閒置磁碟 submitted/completed 相等。
  • 同一組紀錄也驗證檔案寫入與跨兩次重啟讀回、pipe、demo sync、heap 配置／寫入／讀取／釋放。直接開機結束時 WUFS submitted/completed 均為 34058，swap 均為 2，io_errors/protocol_errors 均為零；此為基本路徑檢查，不包含 swap 壓力測試。
  • build/merge-smoke-20261110-093408/：有效磁碟正常掛載且 SHA-256 不變；空白磁碟完成初始化並有 WUFS0002 標記；檔頭損壞與最後一 byte 非零的磁碟均拒絕格式化且 SHA-256 不變。空白案例等到 shell 出現才關閉 QEMU，以確保初始化已結束。
  • VitePress 文件網站建置通過，只有既有 bundle size 提醒。測試腳本與原始 console logs 留在上述本機 build/；未將工具包、磁碟或測試輸出提交到 Git。
  • GUI 互動、損壞 completion／reset timeout／中斷風暴故障注入，以及全面 journal crash recovery 不在本次 smoke test 範圍；先前未驗項目維持 NOT_RUN。
