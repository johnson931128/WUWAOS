研究方法與來源 ​

來源已檢視內容與圖像結構採用方式
MIT xv6 RISC-V BookOrganization、Page tables、Traps、Scheduling、File system、Logging。記憶體圖由位址欄位、表項、下一層表逐級連接；trap 與 context 圖分開硬體／核心路徑。借鑑分層、位址標記和保存／還原的視覺關係；不複製 trampoline、核心佈局或多核心鎖設計。
OSTEPScheduling §7.7、Advanced Page Tables、FSCK/Journaling。由簡化工作負載推演，再加入限制。先列示例假設，再逐步說明；以時間軸對照 ready queue，持久化則明確區分 log 與 home。連到原教材，不在本站重製整章。
OS in 1,000 Lines從 boot 到 syscall／VirtIO／FS 的循序章節；Page Table 連接觀念、程式與觀察。借鑑問題 → 最小流程 → 原始碼的順序。該教材的 RV32／Sv32 範例不能套用到本站 RV64／Sv39。
OSTEP VizToolsScheduling 與索引中的 trap、paging、swapping 示範，以決策步驟串接事件敘述。每一步同時更新圖、狀態和敘述；不複製示範程式或把它的演算法清單當成 WUWAOS 功能。
OS LabCPU Scheduling 的控制區、參數、就緒佇列、Gantt、事件與指標；已用瀏覽器檢視其行動版排列。只保留幫助理解的輸入與視圖；WUWAOS 單核心 RR，不提供該站的多核心、MLFQ 或一般配置策略。
Operating System Concepts 10e官方章節投影片入口與專案 notes/ 對應課程內容。狀態圖、分頁與 I/O 概念以筆記對照；官方投影片使用條款不等於一般公開網站轉載授權，因此不直接搬圖。
Computer Organization and Design RISC-V Edition官方 companion 與書目入口；CPU／記憶體位址與軟硬體界面以本專案筆記及 source 交叉對照。借鑑將指令、暫存器、位址欄位分開說明的教學方向；沒有取得並重製該書內頁圖片，也不宣稱已讀取全部受限教材。

十二章的圖解研究對照 ​

章節原創視覺方案參考案例／圖像結構WUWAOS 差異與 source
Getting StartedA：分層系統地圖；B：學習路線xv6 organization 的核心職責分區；1,000 Lines 目錄 的依賴順序。單一靜態連結 S-mode kernel，UI 也在 S-mode；以 kernel/boot/main.c 與實際目錄分區。
BootB：QEMU → OpenSBI → 磁碟載入器或直接交接 → 核心 → 行程1,000 Lines Boot 的分步啟動敘述。run-disk 由 bootloader/boot.c 讀取 WUFS /boot/kernel.elf。run 與 GUI 由 QEMU -kernel 載入。兩條路徑共用 arch/riscv/entry.S 與 kernel/boot/main.c。
TrapsB：U/S mode 泳道與 TrapFramexv6 trap fig. 4.1 的進入／返回路徑。使用 trap_entry／trap_handler 與共享核心映射；不畫 xv6 trampoline/uservec。ecall 的 sepc+4 與 page fault retry 分開。
ProcessesA/B：PCB、state graph、雙 stack context switchxv6 process layout、context switch fig. 8.2。固定 16 PCB；KernelContext 與 TrapFrame 分工；共用 scheduler stack，無 SMP p->lock。process.c、context.h、swtch.S。
SchedulingC/D：ready queue、Gantt、目前執行者OSTEP RR figs. 7.6–7.7、VizTools scheduling、OS Lab。kernel 固定 50 ms；網站可調 quantum 只是教學比較，沒有改 OS。核心不被 timer 搶占，wait/yield 可合作切換。
MemoryA/B/D：VA bit layout、三級表、PTE 與 framexv6 page tables figs. 3.1–3.4、OSTEP page tables。9/9/9/12 bits，4 KiB leaf only。WUWAOS user VA 小於 2^38；不用 xv6 trampoline 地址、超頁或任意硬體 TLB 模擬。
PagingC：PTE → RAM → swap slot，分成功／rollbackOSTEP swapping、本專案 notes/ch10 Virtual Momory.md。FIFO arrival、pins、VM Gate、先 revoke 再 swap；失敗 restore RAM，外層 fault 才 leave Gate。
I/OA/C：VirtIO descriptor、avail／used、bounce 與 caller1,000 Lines VirtIO、notes/ch12 I_O Systems.md DMA 段落。Block completion 為 scheduler poll；512-byte buffer／16-byte alignment；不是 IRQ 完成或直接 user-buffer DMA。
File SystemA/C：directory → inode → blocks，log 與 homexv6 FS figs. 10.1–10.3、OSTEP journaling。WUFS 80-byte inode、8 direct + 8 indirect、512-byte sector、full-sector bounded redo；不畫 xv6 buffer cache 或 1 KiB block。
ApplicationsB：Shell → FD/OFD → TTY／pipe／file → syscallxv6 interfaces、1,000 Lines syscall。自訂 ABI；GUI 是同一 user shell image；fan safe replace、受限 ELF，沒有 Linux API／argv 相容性。
MonitoringA/B：snapshot → 累積 ticks 差 → CPU／RSS／SwapOSTEP scheduling metrics、notes/ch5 CPU schedueling.md。CPU 為派發期間時間，含該行程 kernel work；不是硬體 utilization、load average 或純 CPU burst。workstate.c。
WritingA/B：source → chapter／Vue → VitePress → gh-pages1,000 Lines 圖文／source 組織、本 repository 發布工具。repo 是唯一來源；無網站編輯後端；教學模型與 OS 驗收分開，歷史 spec 保留。

可追溯性與資產政策 ​

所有圖以 Vue/SVG/CSS 重新繪製，來源僅作概念與圖像結構參考。課程筆記可依使用者授權引用敘述，但其中第三方圖片仍需獨立確認授權。靜態向量圖由 source 管理，文字可搜尋／放大；沒有搬運教材截圖、未授權圖像或將外部模擬器嵌入本站。

一般教材概念、WUWAOS source 行為、網站的簡化假設各自標示。網站互動驗證與 OS runtime 驗證分開記錄，參見詳細計畫。
