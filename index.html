WUWAOS · A SOURCE-BASED OS TEXTBOOK

從第一條指令，到一個真正啟動的作業系統

WUWAOS 以 C 與 RISC-V 組合語言實作，透過 QEMU 在 RV64 虛擬電腦上啟動。這份教材沿著硬體、核心與使用者程式的邊界，連接作業系統觀念、目前原始碼與可觀察操作。

完整系統規格、限制與原閱讀路線

目前的系統邊界 ​

項目現況
平台QEMU virt、RV64、單核心、128 MiB RAM
開機make run-disk 由 flash 載入器從 WUFS0002 啟動 CLI；make run 和 GUI 指令由 QEMU 直接載入核心
執行模式S-mode 核心、U-mode 使用者程式；可選桌面與 UI 服務在 S-mode 核心端
行程最多 16 個 PCB；fork／exec／exit／wait 與事件等待
核心上下文RV64 swtch.S；每行程保留 C 呼叫堆疊、獨立排程器堆疊
同步使用者 Mutex／Semaphore；核心 owner-aware gate 保護 OFD／pipe、FS 與 VM
排程單核心 RR、50 ms 時間片；使用者程式可搶占，核心內不被計時器搶占，但可事件等待／合作式切換
記憶體Sv39 三級頁表、4 KiB 頁、按需分頁、FIFO 置換；直接開機可使用獨立 Swap 磁碟
磁碟runtime Block event wait；WUFS0002 journal／開機重播與原子替換；reset 確認後隔離故障裝置，不能確認仍 fail-stop
操作Shell FD/OFD、三階段管道、檔案重導向、fan 全螢幕文字編輯器
圖形輸出可選 VirtIO GPU/tablet/keyboard；1280×720 桌面、最多四個獨立 Terminal、焦點／拖曳／viewport 裁切與非阻塞 present
監測workstate 全螢幕；每秒更新行程、CPU 派發時間、RSS／Swap 與整體 RAM

這是目前程式碼的實作紀錄，不承諾 Linux 相容。尚無通用 ELF／Linux 相容、網路或檔案管理器。視窗 resize 只裁切固定 100×30 模型，沒有 TTY resize ABI、文字重排或 clipboard。Stack guard 尚無 emergency trap stack；Block 隔離後不自動重掛，GPU 復原失敗會停用 GUI 並保留 DMA storage。目前桌面操作見開機章節，Spec 30 與 Spec 28 保留早期驗收。

文件如何組織 ​

主題章節描述目前設計；原始規格與驗收紀錄 保留開發過程。舊規格中的架構可能已被後續版本取代，閱讀時應留意每份文件的階段說明。

本站以互動教學、架構說明、函式／參數與操作指令連接觀念和實作；完整 OS 原始碼以 GitHub 連結提供，不整段匯入來源檔。OS 與文件變更提交到 main，網站發布另由專用工具處理。驗收結果是各規格記錄的當時操作，網站動畫與建置不代表重新執行過 OS 驗證。
