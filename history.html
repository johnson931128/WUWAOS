原始規格與驗收紀錄 ​

此處按開發順序保存規格。它們記錄「當時做了什麼」，不一定代表現在的架構；第一次閱讀建議先看左側主題章節。 Spec 33 以前的歷史 source link 若指向舊 kernel/ 或 user/ 路徑，固定指向 2026-11-07 重整前 commit 800a805，以保留當時程式碼參照；目前目錄與 UI/kernel 邊界見 Spec 33。

Thread 設計草案（2026-11-10） ​

後續已完成階段 A：PCB／TCB 拆分與回歸。Ready queue、事件與同步等待、KernelGate／mutex owner 已改為 Thread，每個 Process 暫時只有一條；下述使用者多 Thread API 仍未實作。

Spec 34 定義 Process／Thread 資源拆分、單 hart 1:1 排程、create／join／exit ABI、stack／guard、Thread owner、FD／TTY 引用及 Process 群組退出。新增教學章節說明 Thread 在 OS 的角色、CPU／hart／core／SMT 與 context switch。狀態為 NOT_IMPLEMENTED，Thread runtime／故障注入／效能驗收為 NOT_RUN；文件建置不代表核心功能已完成。

CLI 磁碟開機（2026-11-09） ​

2026-11-10 文件補充：新增主機建置、客體開機及 Flash／磁碟／RAM 關係的 ASCII 圖，並同步 portable／WSL 啟動方式與直接開機的差異。磁碟開機原理

make run-disk 交叉編譯核心並安裝到 WUFS0002。QEMU 透過 OpenSBI 進入唯讀 flash 載入器，再從磁碟的 /boot/kernel.elf 啟動 UART shell。使用 QEMU 8.2.2／OpenSBI 1.3 驗證了 PowerShell 啟動至 wuwaos/>、CLI 指令、新磁碟開機、重啟讀回與無磁碟時停止開機。 開機流程 · 實作與驗收範圍 · 實作提交

互動教學整理（2026-11-08） ​

網站以 HTML/CSS/Vue 加入 Block Async I/O、FD/OFD、換頁與 Swap、Journal 與安全替換 的教學模型，按章節分別提交，搭配筆記引用、參數／欄位與函式對照。模型展示的是程式邏輯順序，不是即時 OS、效能量測或新 QEMU 驗收。

大型概念與狀態演示使用 DOM/CSS，自動排版的 Mermaid 僅保留在程式碼關聯與小流程；原始規格的圖片、流程與驗收仍保留歷史位置。第一輪不使用新靜態生成圖或第三方教科書圖片；瀏覽器互動與視覺驗收依使用者要求為 NOT_RUN。

Spec 33 之後的實作進度 ​

後續工作直接記錄於 詳細計畫，不改寫舊規格的驗收紀錄。對照目前程式碼請讀 程式碼導覽 與主題章節。
